## Writing a Descant

### Definition

A **descant** is an independent melodic line written above the soprano part, typically for flute or
violin, played while a choir or congregation sings from the written vocal part. The descant floats
above the texture and provides a countermelodic layer.

**Canonical exemplar:** Bach/Gounod _Ave Maria_ — uses all the principles below and is considered
"the most famous descant of all time."

---

### What to Do (Guidelines)

**1. Create a sense of organization** Use repeating elements — motives, intervals, rhythmic figures.
A descant without internal organization sounds incoherent. Even a simple repeated rhythm or a
consistent intervallic pattern gives the line coherence.

**2. Choose pitches based on the chord beneath** The descant should be harmonically grounded. As
much as possible:

- Select pitches that belong to the current chord
- Avoid using the same pitch that the soprano is already singing (especially avoid doubling the
  soprano's exact note)
- Avoid the alto's note as well, if possible **3. Add dissonance** Dissonance makes music
  interesting. Include:
- **Passing tones** — non-chord tones that move stepwise between chord tones
- **Appoggiaturas** — non-chord tones approached by leap and resolved by step (usually downward)
- Neighbor tones, suspensions, and other standard non-harmonic tones **4. Create contrapuntal
  independence from the soprano**

This is the most important structural principle:

| When soprano...                      | Descant should...                      |
| ------------------------------------ | -------------------------------------- |
| Goes up                              | Go down (or stay the same)             |
| Goes down                            | Go up (or stay the same)               |
| Has many intervallic leaps           | Be more stepwise and static            |
| Is stepwise and smooth               | Include more leaps and activity        |
| Has longer note values               | Fill with faster, more active notes    |
| Has faster, busier rhythm            | Sustain longer note values             |
| Climbs to a high register mid-phrase | Return to lower register by phrase end |

**5. Phrase arch: return to origin** If the descant rises to a high point in the middle of a phrase,
it should come back down to approximately its starting register by the end of the phrase. Mirror the
phrase shape of the underlying music.

---

### What to Avoid

- **Parallel motion with the soprano** — moving in the same direction at the same interval
- **Doubling the soprano line** — the descant should never simply double what the soprano sings
- **Rhythmic mirroring** — the descant's rhythm should not constantly match or echo the rhythm of
  the existing vocal parts

---

### Motivic Quotation in Descants

A descant can incorporate brief quotations from other music or from the same piece. Guidelines:

- **Use short, recognizable motives** — a four-note gesture is often enough to be recognizable
- **Avoid long verbatim quotes** — they sound contrived
- **Alter quoted material** through:
  - **Diminution:** Shorten note values (e.g., halve all note values)
  - **Augmentation:** Lengthen note values (e.g., double all note values)
  - Inversion, retrograde, rhythmic displacement **Historical examples of quotation technique:**
- Bach quotes himself and folk material in the Goldberg Variations finale
- Schumann quotes Beethoven's _An die ferne Geliebte_ in the Fantasie Op. 17; also quotes himself
- Debussy mockingly quotes Wagner's _Tristan und Isolde_ in _Golliwog's Cakewalk_ (≈1:15)
- Jazz musicians quote familiar melodies in improvised solos (Bill Evans' anagram references)

## Pedal Point

### Definition

A **pedal point** is a single note sustained (or repeated) in one voice — almost always the bass —
while other voices change harmony above it. It continues "for an abnormally long amount of time"
relative to normal harmonic rhythm.

Pedal points are "fabulously effective" for creating large-scale tension or spaciousness.

---

### Two Types by Scale Degree

#### Tonic Pedal (Scale Degree 1)

- Bass sustains on the root of the home key (scale degree 1, root position)
- **Effect:** Static, spacious, floating — "no need to go forward or backward"
- Creates openness and room to grow; does not build urgency
- **Best for:** Establishing a mood, creating space for melodic development, conveying peace or
  stillness **Examples:**
- Bill Evans, "Peace Piece" — extended vamp on C major, white-note pitches throughout
- Wagner, _Das Rheingold_ Overture — nearly 5 minutes on E♭, orchestral instruments build over a
  static bass

#### Dominant Pedal (Scale Degree 5)

- Bass sustains on scale degree 5 (or the bass of I⁶₄, which is also scale degree 5)
- **Effect:** Tension-building, energetic, demanding resolution — "far more tension than tonic"
- The dissonance between the sustained bass and the changing harmonies above generates directed
  energy
- When the bass finally moves, the release is "an exhilarating moment"
- **Best for:** Building to a climax, creating urgency, intensifying a section before a cadence
  **Refinement:** I⁶₄ in the bass (scale degree 5 in the bass with the tonic chord in second
  inversion above it) creates even more tension than plain scale degree 5, because the listener is
  waiting for the cadential resolution.

**Examples:**

- Bach, _St. John Passion_, opening movement — stabbing bass notes that refuse to yield, dissonant
  upper voices throughout
- Bach, C Major Prelude, WTC — dominant seventh bass from 1:21, builds then resolves to I7 (delays
  full resolution)
- Chopin, Nocturne Op. 9 No. 1 — same bass note held for approximately 50 seconds at 3:10
- Debussy, _Voiles_ (Préludes, Book I) — fixed low B♭ throughout; middle section shifts from
  whole-tone to pentatonic while bass is unchanged

---

### Construction Principles

There is no single prescribed method. Two levers control the effect:

**Lever 1: Which scale degree to hold**

- Scale degree 1 → static, peaceful
- Scale degree 5 (or I⁶₄ bass) → tension, urgency
- Other sustained pitches (scale degree 2, ♭7, etc.) are possible but less common **Lever 2: When to
  release the pedal** The moment of release carries great compositional weight. Choose it
  deliberately:
- Release at a structural high point (climax, phrase arrival) for maximum impact
- Delay release as long as possible while the dissonance remains interesting
- "Choose the release carefully for maximum effect" **Tolerance for dissonance:** When the changing
  harmonies above do not perfectly fit the pedal note, this is acceptable and often desirable:

> "Even when the pedal point doesn't fit all of the immediate chords you are holding it under, it's
> not a bad thing — assuming it will eventually fit at the point where you change the bass."

Scale degree 5 is particularly flexible because it belongs to both I (as the fifth) and V (as the
root) — two of the most common chords — so it will always "fit" at important structural moments.

## Introductions and Outros

### Purpose of an Introduction

A well-crafted introduction:

- Establishes the **key** and **mode** unambiguously
- Creates the **character** and emotional tone of the piece
- Introduces a **motivic idea** that can return in interludes and the outro
- **Extends the form** — hymns are typically only 16–20 measures; an intro adds length and formal
  weight
- Raises the listener's expectations before the melody enters

---

### Six Strategies for Building an Introduction

**Strategy 1: Short Melodic Motive from the Piece**

Extract a brief motive — as few as the opening four notes — and develop it.

- The motive establishes the character before the full melody is heard
- Development can include: repetition at different pitch levels, sequence, fragmentation
- Example: "Come, Come Ye Saints" — the first four notes alone establish the character completely
  **Strategy 2: Rhythmic Motive from the Piece**

Use the same _rhythm_ as the opening motive, but with different pitches.

- Separates rhythm from melody as an independent motivic element
- The recognizable rhythmic fingerprint is present; the pitches are new
- Creates connection to the piece while offering fresh material **Strategy 3: Melodic Inversion**

Take a motive and invert it — every interval that went up now goes down, and vice versa.

- Works especially well for melodies with distinctive intervallic leaps (rather than stepwise
  motion)
- The result sounds unique yet unmistakably related to the source
- Example: "Our Savior's Love" — melody F#–A–F#–B → inversion: A is now _below_ F# instead of above
  **Strategy 4: Abstraction ("Phone Number Method")**

Generate a motive from abstract interval selection.

- Choose interval sizes from an arbitrary source (e.g., last two digits of a phone number)
- Example: digits 4 and 9 → use fourths and ninths as the primary intervals
- In C major: F (a 4th above C) and D (a 9th above C) → build a motive from F and D reaching up to G
- Transpose the resulting motive to match the underlying harmonic changes **Strategy 5: Unusual
  Chord Progression**

Introduce a distinctive chromatic progression as the harmonic framework of the intro.

- Example: I – ♭III – iv (tonic, flat mediant, minor subdominant)
- These borrowed/mixture chords immediately establish a sophisticated harmonic palette
- Develop this progression for several measures as the intro
- **Transition to the piece:** End the intro on:
  - **V** (bare dominant, strong) — creates maximal tension before the hymn's I
  - **I⁶₄ → V** (cadential six-four before dominant) — even more tension, recommended **Strategy 6:
    Postlude / Outro**

The outro mirrors the introduction in character and material:

- Reuse motivic material from the intro
- Provide harmonic closure (I⁶₄ → V7 → I, or a deceptive cadence for added color)
- Use as a coda that reinforces the emotional character established at the opening
- Can extend the final chord with pedal point for spaciousness or tension

---

### Ending the Introduction: Preferred Approaches

Before the melody enters, create tension:

| Ending          | Tension level | Effect                                              |
| --------------- | ------------- | --------------------------------------------------- |
| V7              | High          | Classic dominant, strong expectation                |
| I⁶₄ → V7        | Higher        | Dominant prolonged: 6/4 suspensions resolve into V7 |
| ♭III → V7       | Very high     | Borrowed chord adds exotic weight before resolution |
| V7/I with pedal | Highest       | Sustained dominant urgency                          |

**Consistently recommended:** I⁶₄ before the final I at any structural arrival point. This adds
maximum tension before resolution and is a recurring theme across all cadential patterns in this
system.

---

## Synthesis: These Techniques Together

In a fully arranged piece (e.g., a hymn with multiple verses), these elements combine as a formal
architecture:

```
[Introduction]
  → motivic material, unusual harmonic progression
  → ends on I⁶₄–V7 for maximum tension

[Verse 1] — standard harmonization
  → basic I–IV–I⁶₄–V7–I framework
  → perhaps one secondary dominant or minor iv for color

[Interlude between verses]
  → reuse intro motive
  → pedal point to build tension
  → new chromatic chord (♭VII or ♭III) if appropriate

[Verse 2+] — reharmonized
  → deceptive cadence principle (substitutions)
  → borrowed chords (iv, ♭VII, ♭III) matching text
  → secondary dominants on key structural chords

[Final verse or climactic verse]
  → common-tone modulation to distant key (if using)
  → augmented sixth chord for dramatic pre-dominant
  → full cadential motion: Ger⁺⁶ → I⁶₄ → V7 → I

[Outro / Postlude]
  → motivic callback to intro
  → pedal point on tonic for spaciousness, or I⁶₄ for lingering tension
  → final authentic cadence
```
